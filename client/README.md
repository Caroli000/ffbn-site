# FFBN - Frontend

Site officiel de la FFBN (Fédération des Étudiants Burundais) — frontend Vue 3 avec un espace Admin complet.

- Front‑end moderne : Vue 3, Vite, Vue Router, i18n
- Espace Admin : tableau de bord sécurisé pour gérer contenus, événements, newsletters, médias et utilisateurs
- API back‑end : le projet inclut un serveur Express.js (API REST) pour authentification, CRUD et gestion médias

Pour la documentation complète et les instructions d'installation, consultez le README à la racine du dépôt parent.
