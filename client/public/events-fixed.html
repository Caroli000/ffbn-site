Problème Résolu!
Les événements s'affichent maintenant correctement sur la page d'accueil.

❌ Problème Identifié

Les contrôleurs publics (EventController, ActionController, StatsController) appelaient des méthodes asynchrones sans utiliser await.

Cela signifiait que les réponses retournaient des promesses non résolues au lieu des données réelles.

getUpcoming(req, res) { const events = this.service.getUpcoming(lang); // ❌ Retourne une Promise! res.json({ success: true, data: events }); // data = Promise }

✅ Solution Appliquée

Conversion de toutes les méthodes pour être correctement asynchrones avec async/await :

async getUpcoming(req, res) { try { const events = await this.service.getUpcoming(lang); // ✓ Attend le résultat res.json({ success: true, data: events }); // data = Array } catch (err) { res.status(500).json({ success: false, message: err.message }); } }

  • server/controllers/ActionController.js

  • server/controllers/StatsController.js
